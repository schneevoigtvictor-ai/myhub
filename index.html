Wo liegt die Datei?
Im GitHub-Repo schneevoigtvictor-ai/myhub. GitHub Pages stellt sie automatisch unter schneevoigtvictor-ai.github.io/myhub bereit.

Wie aktualisiere ich?
1. Claude Cowork oeffnen (Chrome-Freigabe aktiv)
2. Sage: "Oeffne index.html, suche COWORK-UPDATE: HIGHLIGHTS und aktualisiere den JSON-Block"
3. Terminal: git add . && git commit -m "Update" && git push
4. Seite aktualisiert sich in 1-2 Min automatisch

Spaeter automatisieren?
Git-Push per Cowork oder GitHub Action moeglich. Alle Datenbloecke sind per str_replace austauschbar.
